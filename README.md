# Payment Analytics & Insights — Power BI Dashboard

## 📊 Project Overview

Payment Analytics & Insights is an interactive Power BI dashboard designed to analyze payment and transaction data and provide insights into transaction volume, transaction values, users, services, payment status, customer age groups, and monthly trends.
The dashboard transforms raw transaction and user data into an interactive visual report, allowing users to explore key payment metrics and identify trends through filters and interactive visuals.

--

##  Purpose
The main objective of this project is to create a centralized analytics dashboard that helps understand:

> Overall transaction performance
> Total transaction value
> Number of transactions
> Total users
> Monthly transaction trends
> Transaction performance by service
> Customer/user distribution by age bracket
> Transaction value across users
> Weekend vs. non-weekend transaction activity
> Payment status distribution and filtering
> 
The dashboard is designed to make payment data easier to understand through interactive KPIs and visual analytics.

---

* **Power BI Desktop** — Dashboard development and data visualization

The dataset used for this project was obtained as an **Excel file from a YouTube resource** and was imported into Power BI for analysis.

# ✨ Features & Highlights

## 1.  KPI Cards
The dashboard provides high-level KPIs to quickly understand overall performance, including:

* **Total Transaction Value**
* **Total Transactions**
* **Total Users**
* **Transactions for the selected month**

These KPIs provide a quick snapshot of the payment ecosystem.

---

## 2.  Monthly Transaction Analysis
The dashboard includes monthly trend analysis to visualize how transaction activity changes over time.

The area charts help identify:
* Monthly transaction volume
* Changes in transaction values
* Transaction trends across different months

---

## 3.  Transaction Value by Service

A **clustered bar chart** provides a comparison of transaction values across different services.

This allows users to understand which services contribute to the overall transaction value.

---

## 4. 👥 User Age Analysis

A **donut chart** visualizes users based on different **age brackets**.

This helps provide an understanding of the customer/user demographics within the dataset.

---

## 5. 👤 User-Level Analysis

The dashboard includes a visual comparing users with transaction-related metrics.

This can be used to explore transaction activity and transaction values associated with individual users.

---

## 6.  Weekend vs. Non-Weekend Analysis

A **pie chart** compares transaction values based on whether transactions occurred during:

* Weekend
* Non-weekend

This provides an additional perspective on transaction behavior based on the day type.

---

## 7.  Interactive Filters

The dashboard includes interactive slicers that allow users to filter the report dynamically.

### Available filters include:

* **Month**
* **Payment Status**

Changing these filters dynamically updates the relevant dashboard visuals and KPIs.

---

## 8.  Interactive Tooltip

A dedicated **report-page tooltip** has been created for transaction-value analysis.

When users hover over relevant data points, the tooltip provides additional transaction information without requiring them to leave the main dashboard.

This improves the interactivity and usability of the report.
